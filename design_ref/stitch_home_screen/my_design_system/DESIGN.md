# Design System

This document outlines the core principles and specifications of our design system.

## Theme

### Color Palette
- **Color Mode**: light
- **Primary Color**: `#777777` - The brand's most distinctive chromatic color, suitable for buttons, CTAs, and key interactive elements.
- **Secondary Color**: `#777777` - A supporting color for less prominent UI elements, chips, and secondary actions.
- **Tertiary Color**: `#000000` - An additional accent color for highlights, badges, or decorative elements.
- **Neutral Color**: `#777777` - A neutral base color for backgrounds, surfaces, and non-chromatic elements.

### Typography
The font family chosen across the system ensures clarity and brand consistency.
- **Headline Font**: `inter`
- **Body Font**: `inter`
- **Label Font**: `inter`

### Shape and Form
- **Roundedness**: 2 (Moderate) - This value dictates the corner radius of UI elements, contributing to the overall feel of the interface. A moderate roundedness offers a balanced, friendly appearance.

### Spacing
- **Spacing**: 2 (Normal) - This defines the relative level of whitespace, impacting readability and visual hierarchy. Normal spacing provides a balanced layout.
